# 11 · Apresentação do projeto

A apresentação no Google Apresentações é a **fonte oficial** das informações compartilhadas com os times de Comercial, Jurídico, Financeiro, Projetos e Marketing.

📊 **[Abrir a apresentação](https://docs.google.com/presentation/d/1bl0wN23E9dkoMUbHelX5vJ8wT0NXF0qhrQ9Psw3r_BI/edit)**

> O acesso depende das permissões de compartilhamento no Google. Se aparecer "acesso negado", peça acesso ao responsável pelo projeto.

## Como este repositório e a apresentação se relacionam

| | Apresentação | Repositório |
|---|---|---|
| **Papel** | Comunicação com os times e validação das propostas | Documentação do processo e base do sistema futuro |
| **Atualização** | A cada rodada de validação | Quando uma decisão é tomada ou o processo muda |
| **Público** | Times internos | Time do projeto e portfólio |
