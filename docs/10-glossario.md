# 10 · Glossário

| Termo | Definição |
|---|---|
| **Aderência** | Análise técnica que verifica se a operação do cliente cabe no padrão do 3S Checkout |
| **Ativação / go-live** | Momento em que a loja começa a operar com o 3S Checkout |
| **Briefing técnico** | Levantamento das informações e particularidades da operação do cliente |
| **Checklist do cliente** | Lista de informações e acessos que o cliente precisa entregar antes do setup |
| **Contrato de setup** | Contrato de prestação de serviço que formaliza o setup, as obrigações dos dois lados e as consequências do descumprimento |
| **Contrato de licença** | Contrato da assinatura recorrente da plataforma |
| **Deal** | Oportunidade comercial acompanhada no pipeline comercial |
| **Homologação** | Testes e aceite formal do cliente antes da instalação |
| **ICP** | Perfil de cliente ideal: as contas elegíveis para o teste |
| **Instalação** | Etapa em loja antes da ativação. Pode ser parcelada nas primeiras mensalidades |
| **Piloto** | Caminho opcional em que a loja opera por 30 dias corridos antes da conversão |
| **Portão** | Ponto de decisão com critérios objetivos para a conta avançar (P1, P2, P3) |
| **Pré-pago** | Modelo em que o setup é pago antes de começar |
| **Projeto** | Implantação acompanhada no pipeline de projetos, criada a partir do deal |
| **Setup** | Configuração do PDV: cardápio, integrações, parâmetros fiscais e operacionais |
